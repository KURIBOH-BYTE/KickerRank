# T39 · Verteidigung üben: jedes Mitglied erklärt jede Schicht

**Meilenstein:** M6 · Abgabe und Verteidigung  
**Schicht/Typ:** Verteidigung  
**Schätzung:** 3 h  
**Abhängig von:** T27

## Ziel
Jedes Mitglied kann alle Teile konzeptuell und im Code erklären (50 % der Note).

## Aufgaben
- [ ] Fragenkatalog sammeln (z. B. «Warum liegt die Elo-Berechnung nicht im JavaScript?», «Was ist der Unterschied zwischen DTO und Message?»)
- [ ] Gegenseitig abfragen, jede Person zu jeder Schicht
- [ ] Einen Request im Debugger durch alle Schichten verfolgen

## Akzeptanzkriterien
- [ ] Jedes Mitglied hat jede Frage mindestens einmal beantwortet

## Tests
- [ ] Probeverteidigung

## Definition of Done
- [ ] Akzeptanzkriterien erfüllt
- [ ] Tests geschrieben und grün (`pytest`)
- [ ] Von einem anderen Gruppenmitglied gereviewt
- [ ] Quellen in T36 ergänzt (falls etwas Neues verwendet)
