**Meilenstein:** M6 · Abgabe und Verteidigung  
**Schicht/Typ:** Test  
**Schätzung:** 1 h

## Ziel
Sicherstellen, dass das Projekt beim Dozenten startet.

## Aufgaben
- [ ] Frisch klonen auf einem Rechner, der noch nie daran gearbeitet hat
- [ ] Nur nach README vorgehen, inklusive MySQL installieren und `docs/setup.sql` ausführen
- [ ] `pytest` und `python main.py`
- [ ] ZIP für Moodle erstellen (ohne `.venv`, `__pycache__`, `.pytest_cache`)

## Akzeptanzkriterien
- [ ] Start und alle Tests funktionieren ohne Nachbessern

## Tests

## Hinweise
Mindestens 2 Tage vor der Deadline erledigen. Die MySQL-Einrichtung ist der heikelste Teil, darum genau so testen, wie es der Dozent machen wird.

- [ ] Akzeptanzkriterien erfüllt
