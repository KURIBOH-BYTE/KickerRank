# T02 · Entwicklungsumgebung für alle Gruppenmitglieder

**Meilenstein:** M0 · Setup und Planung  
**Schicht/Typ:** Setup  
**Schätzung:** 1 h  
**Abhängig von:** T01

## Ziel
Alle können das Projekt klonen, starten und Änderungen pushen.

## Aufgaben
- [ ] Repository klonen: `git clone https://github.com/KURIBOH-BYTE/KickerRank.git`
- [ ] venv erstellen, aktivieren, `pip install -r requirements.txt`
- [ ] In VS Code «Python: Select Interpreter» → `.venv` wählen
- [ ] Testweise einen Branch pushen und wieder löschen

## Akzeptanzkriterien
- [ ] Jedes Mitglied hat das Projekt lokal gestartet
- [ ] Jedes Mitglied hat mindestens einmal gepusht

## Tests
- [ ] Manuell pro Person: `python main.py` und Seite im Browser öffnen

## Hinweise
Anleitung: `e1_ex0_Dev_Env_VS.pdf`. Ein Kommentar pro Person im Ticket, sobald es läuft.

## Definition of Done
- [ ] Akzeptanzkriterien erfüllt
- [ ] Tests geschrieben und grün (`pytest`)
- [ ] Von einem anderen Gruppenmitglied gereviewt
- [ ] Quellen in T36 ergänzt (falls etwas Neues verwendet)
